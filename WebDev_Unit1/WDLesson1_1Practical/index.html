Web Technologies

HTML

A HyperText markup language used to bring in elements to a webpage. Mainly used to write text inside of a webpage. Cant style Or make interactions with text.

CSS

Cascading style sheets is a styling language used to style text. It can Change fonts, color texts, and make everything look more visually appealing. Can not directly modify html code.

JAVASCRIPT

JavaScript Is a giant programming language that can help make websites, games and a lot more. Can modify page content, Do visual effects, And Interactions between things. Can not manage device memory manually, or bypass built-in browser security models.
